UBS help and support

Installation, account activation, backups and download verification for UBS customers.

Start your trial or activate a plan

Eligible new customers can start a 15-day free trial by creating a UBS account and verifying their email. Contact KD FINCORP to activate a paid plan and arrange setup.

UBS Single PC costs ₹5,999 per year for one Windows PC. UBS LAN costs ₹8,999 per year for two Windows PCs, including the host. Additional LAN PCs cost ₹1,000 per PC per year. Prices exclude applicable taxes. View all plans and device allowances.

Existing approved licences and trial periods retain their agreed terms. Approved licence changes can be applied through Settings > Account & licence > Sync licence now.

Install or update UBS

  1. Complete any unfinished entries and save a recovery backup before updating.
  2. On Windows, run the installer and use your existing UBS installation folder to retain saved books and account information.
  3. On Android, install the APK over your existing app. Do not uninstall UBS or clear its storage.
  4. Allow all installation and recovery checks to finish before reopening your books.

In UBS, use Help > Check for updates to check for an available release. Interrupted downloads can resume when supported. Only verified update files are offered for installation.

Backups and recovery

Cloud backup is included with annual plans, within the account storage allowance. Keep a separate local recovery copy and store its password securely.

Allow backup operations to finish before shutting down the computer. A new cloud backup requires the designated PC to be running and connected to the internet. Open Company Data & Backups to view the last verified cloud backup or retry an incomplete upload.

Restoring a backup replaces the saved books in that installation. Contact support before restoring or moving books if you need help selecting the correct copy.

Set up the accounting assistant

On Windows, the first use of the AI assistant downloads a model of approximately 2.5 GB directly to your PC. An internet connection is required for this initial download. Progress is displayed in the assistant, and interrupted downloads can be resumed. The model runs locally after setup; an existing model is retained when you update UBS.

Android provides bundled app guidance and supported local report answers. It does not use the Windows AI model.

Review all suggested accounting entries and extracted invoice details before saving them. Assistant suggestions do not post transactions automatically.

Scan and review a bill on Windows

Open Scan bill from PDF / image and choose the source file. Compare the extracted party details, GSTIN, items, quantities, rates, tax and totals with the original document. Correct any errors before confirming your review.

Select Save reviewed bill to save a confirmed entry, or Open in bill form to continue editing without posting. Financial-year checks still apply, and entries cannot be saved to a finalised year.

Use UBS with your office team

UBS LAN includes two Windows PCs, including the host. Staff use the same company records over the office network, with access controlled by their assigned permissions. The host PC must remain available while staff are working.

If support has configured the separate host application, download UBS LAN Server 3.6.2. Retain its existing data folder and private settings when updating.

For access from different locations, enquire about the Connected pilot. Contact support before changing an existing mobile setup so that previously recorded entries can be reviewed.
