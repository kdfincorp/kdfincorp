UBS help and download verification

Install Windows 3.5.6

Download the 173.4 MB Windows installer and run the single EXE. No BIN files are needed. Back up existing books and install over your existing UBS folder to retain your data and activation.

Full AI with a smaller installer

All features and the full AI runtime are included. The unchanged AI model is a separate one-time download of about 2.5 GB. Ask Pengu your first AI question while connected to the internet; the app downloads and verifies the model directly to your PC. Its progress appears in the assistant, and Cancel preserves progress for a later retry. Once setup completes, inference runs offline. An existing model is reused without downloading again.

The model is hosted externally; it does not occupy Oracle storage and Oracle does not proxy the model download. Direct AI model download is available for manual setup. If downloading manually, keep its original filename and place it in the app's _internal/accounting_ai folder. The model SHA-256 is 8cdb57cbb880d313736a9bc4e3d3d2485f145b5e19cf33783746e753e82641fc.

Scan and save a bill

Choose Scan bill from PDF / image, check the original against the extracted party, GSTIN, items, quantities, rates, tax and total, tick the review confirmation and select Save reviewed bill. The app asks before switching to the bill's existing financial year. Finalized or missing years remain blocked. Open in bill form prepares an editable entry without posting it. OCR can still misread faint text and similar GSTIN letters; correct them before saving.

Updates and login

Startup update checks show availability in Help without interrupting login. Use Help > Check for updates to download an available version. Interrupted downloads retry and resume when supported. Incomplete or unverified files are never installed. A download failure allows continued use of UBS.

Keep your books safe

  • Before upgrading or switching devices, save a complete .ubsbackup recovery copy and retain its recovery password separately.
  • Restore replaces the complete collection of books. Use Add Companies to import a separate company database.
  • Devices sharing a baseline can merge new INR receipts and payments when staff protection is off. Other concurrent changes require an explicit choice; recovery copies are retained before replacement.
  • A fresh backup requires the device or configured backup host to be running. Check local recovery and cloud-upload status separately.
  • Update Android by installing over the existing app. Uninstalling or clearing app storage removes its local books and encryption keys.

Activation on iPhone

Export KD Owner Phone.json from PC KeyGen's iPhone setup. Transfer it privately to Files, select it in KD Activation, and enter its export password. Keep the signing file and password private.

Get support

Send the application version, device type, the action that failed and the visible error. In versions containing System Health, use Help → System Health → Save support report. Review any other diagnostics before sharing. Keep company books, passwords and signing files private.

Official downloads and customer access

Automatic backup and updates

Windows 3.5.6 supports opt-in live cloud backup for eligible paid accounts while the PC is running and connected. Retention keeps the current cloud backup and the last two Tuesday snapshots when available. Local daily backups remain separate. Android 3.4.1 continues to use its existing scheduled backup job; background and battery settings can delay it.

Recovery copies are validated before updates, restores and sync replacement. Keep your backup password safely. Install updates over the existing app without clearing storage.

Offline accounting assistant

In UBS 3.2.5, open Help > UBS Assistant. The bundled local model answers supported accounting questions using the selected company and period, and provides app guidance without requiring an open company. No API key or model download is required. Answers identify their report or local-guide source.

Use the examples in the greeting or type a question about profit, cash/bank, sales, receivables, payables, cash flow or overdue reminders. Ask how to use backups, sync, ledgers, inventory items, invoice drafts or reconciliation. Attach invoice extracts a draft for review; it never posts a bill automatically. Image OCR is available on Windows; Android accepts PDF/text drafts.

Chat about a journal entry

Use Ask UBS in the corner, or Help > UBS Assistant. Try: Paid office rent of 10,000 through bank. The assistant proposes debit and credit lines, explains the treatment and provides a narration. If a detail is missing, answer in the same chat. For a loan repayment, confirm total and interest; for tax entries, confirm taxable value, tax components and eligibility. Proposals require review and do not save a voucher.

Use Attach invoice or Business overview inside the chat. Minimize it to return to the form you were editing. Conversation context clears when the company or user changes. The assistant processes locally; configured backup and sync settings continue to apply.

One app, activation-based upgrades

Use the same Windows installer or Android APK for trial, Single Device, Multiple Devices and Windows + Android plans. Admin approves the devices, allowance and validity. Open Settings → Account & licence → Sync licence now to apply an approved change. No app reinstall is needed for later plan upgrades.

Older separate editions need one normal update to the shared app. Existing Windows installations should keep their current installation folder. If you previously used a portable Windows app, keep its books and recovery backup and import or restore them into the installed app. Update Android over the existing app so its books and activation remain in place.

Scan a bill on Windows

Open Scan bill from PDF / image, choose your file, and check the extracted party, items, quantities, prices, GST and total against the original. Create missing parties and items in the review screen. Confirm the reviewed details, then select Save reviewed bill. Choose Open in bill form for further editing without posting. OCR works offline and may misread faint text or product codes.

Allocate receipts and payments

When saving a receipt/payment voucher for a debtor or creditor, choose whether to link it to unpaid bills. Allocate the amount to selected bills; an unallocated balance remains an advance.

Live Windows cloud backup

Enable live cloud backup for an eligible account. Uploads continue while the PC is running and online; cloud retains the current backup and the last two Tuesday snapshots when available. Keep a separate local copy. Android backup behaviour remains unchanged.
