Current UBS release

Windows 3.6.14.0 — Dashboard, navigation and support reporting

  • Redesigned the dashboard for clearer business summaries, smoother scrolling and improved visual hierarchy.
  • Added Back navigation and interactive dashboard detail views, including top debtors and creditors with direct ledger access.
  • Moved diagnostics work off the interface thread so the application remains responsive while checks run.
  • Unexpected errors are recorded locally and can be shared with the technical team by email or WhatsApp after the user explicitly chooses a channel. UBS never sends reports automatically.
  • Retains secure company-password recovery and existing accounting, inventory, reporting, backup and Pengu features.

Version 3.6.14.0 is the only supported Windows download. Back up your books, close UBS and install the update into the existing UBS folder.
